# Acceptance evidence

Version 1 is done when every acceptance criterion in the PRD has recorded evidence. This file records it phase by phase. Each entry names the automated test or CI step that shows the criterion, as `File` › `Test`, under `tests/Palanca.Tests/`. An entry marked *(client)* is under `tests/Palanca.Client.Tests/`, which tests the client package on its own. Criteria that depend on the VPS or on HogarHero name the phase that will add their evidence.

Status, after Phase 2:

- **Met:** the evidence in this repository is complete.
- **Partly:** what Phases 1 and 2 own is shown; the rest comes in the phase named.
- **Phase N:** nothing to show until that phase.
