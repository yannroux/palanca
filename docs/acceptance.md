# Acceptance evidence

Version 1 is done when every acceptance criterion in the PRD has recorded evidence. This file records it phase by phase. Each entry names the automated test or CI step that shows the criterion, as `File` › `Test`, under `tests/Palanca.Tests/`. Criteria that depend on the client, the management API or the VPS name the phase that will add their evidence.

Status, after Phase 1:

- **Met:** the service's evidence is complete.
- **Partly:** what Phase 1 owns is shown; the rest comes in the phase named.
- **Phase N:** nothing to show until that phase.
